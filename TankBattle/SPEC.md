# Tank Battle — SPEC v0.1

## 目標
以經典紅白機 Battle City 為參考的原創 HTML5 2D 像素風坦克遊戲。純前端、無建置流程、可部署 GitHub Pages。

## 技術
- HTML5 Canvas 2D、JavaScript ES6、requestAnimationFrame。
- 13 × 13 格地圖，每格 32px，Canvas 416 × 416。
- 第一版採單檔 index.html，後續依需要拆分模組。

## 第一版 MVP（已實作）
- 玩家 WASD／方向鍵移動，Space 射擊；手機觸控方向與射擊。
- 玩家三條生命、重新開始。
- 敵人從上方三個位置生成，最多同時四輛；共 20 輛。
- 敵人隨機巡邏、轉向、射擊。
- 磚牆可破壞；鋼牆阻擋子彈與坦克。
- 玩家、敵人、子彈與障礙基本碰撞；基地被擊中即失敗。
- 擊破 20 輛敵人獲勝。

## 待改善與後續階段
- 完整坦克間碰撞、出生保護與無敵時間。
- 更精細的磚牆局部破壞；河流、草地、冰面與遮蔽層。
- 敵人種類、關卡資料、道具、音效、爆炸動畫、計分。
- 進階 AI 與遊戲暫停、生命 UI。
- 補充自動化驗證與跨裝置實機測試。

## 驗收
1. 直接開啟 TankBattle/index.html 即可運行。
2. 鍵盤與觸控可移動及射擊。
3. 射擊可破壞磚牆但不能破壞鋼牆。
4. 基地被擊中或玩家生命歸零時結束。
5. 消滅 20 輛敵人後顯示過關。

> 本版本為最小可玩原型，不宣稱完全還原原作。

## 本次調整
- 每次開始及重新開始時，隨機配置一般磚牆；固定保留基地防護、鋼牆與出生點周圍安全空間。
- 同時最多出現 3 輛敵方坦克，整關仍有 20 輛。
- 每輛敵方坦克需被玩家砲彈擊中 3 次才摧毀，前兩次僅扣血並播放命中音效；坦克顏色隨剩餘生命改變。
- 隨機地圖暫不保證所有區域連通。
